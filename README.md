# 智链平台 DSH 插件体验版




为 DeepSeek Harness 增加「智链平台」左侧入口和 Agent 能力与任务中心面板。运行文件已预先构建，安装时无需自行编译。




## 通过地址安装




在 DSH 左侧打开「插件 → 添加插件」，粘贴完整仓库地址：




```text
https://github.com/Easton2026/juslink-dsh-agent-center.git
```




按提示安装并选择「立即启用」。如果 DSH 提示需要重启，按提示处理。之后点击左侧「智链平台」。DSH 会自行下载插件，无需手动解压或维护本地文件夹。




## 体验




在「能力与任务」页面，找到「直接任务」并点击「查看」，查询演示单号 `DEMO-SH-001`。等待返回结果后，进入「任务工作台」回看。




其他单号会明确返回无模拟数据的提示。模拟记录仅保存在使用者当前客户端，不会同步给仓库维护者或其他用户。
