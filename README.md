# 智链平台 DSH 插件体验版

为 DeepSeek Harness 增加「智链平台」左侧入口和 Agent 能力与任务中心面板。运行文件已预先构建，无需自行编译。

## 通过地址安装

在 DSH 左侧「插件 → 添加插件」粘贴：

```text
https://github.com/Easton2026/juslink-dsh-agent-center.git
```

安装并选择「立即启用」，如提示重启则按提示处理。之后点击左侧「智链平台」。DSH 会自动下载安装，无需手动解压。若曾留下安装失败的旧版本，请先在插件列表卸载，再重新安装。

## 体验与范围

在「能力与任务」中找到「直接任务」，点击「查看」，查询演示单号 `DEMO-SH-001`，再进入「任务工作台」回看结果。其他单号会返回无模拟数据的提示。

模拟记录保存在使用者当前客户端，不会同步给维护者或其他用户。成果中心、场景专家和工作方法目前展示产品范围，未接入真实业务系统、LLM 自主规划、DSH Skill 执行或动态 HTML 成果。

## 停用与更新

在 DSH「插件」中停用或卸载 `@juslink/agent-center-ui`，按提示重启。更新使用 DSH 提供的更新操作；不支持更新的版本可卸载后重新安装。

## 文件与维护

仓库只包含 package.json、index.js、client.js、cordis.patch.yml、README.md。图标及样式包含在已构建的 client.js 内。没有用户配置、凭证、真实业务数据或安装脚本。未修改 DSH 官方源码；官方扩展接口变化后仍需要验证兼容性。
