# 智链平台 DSH 插件体验版

为 DeepSeek Harness 增加「智链平台」左侧入口和 Agent 能力与任务中心面板。运行文件已预先构建，安装时无需自行编译。

## 通过地址安装

在 DSH 左侧打开「插件 → 添加插件」，粘贴完整仓库地址：

```text
https://github.com/Easton2026/juslink-dsh-agent-center.git
```

按提示安装并选择「立即启用」。如果 DSH 提示需要重启，按提示处理。之后点击左侧「智链平台」。DSH 会自行下载插件，无需手动解压或维护本地文件夹。

## 体验

在「能力与任务」页面，找到「直接任务」并点击「查看」，查询演示单号 `DEMO-SH-001`。等待返回结果后，进入「任务工作台」回看。

其他单号会明确返回无模拟数据的提示。模拟记录仅保存在使用者当前客户端，不会同步给仓库维护者或其他用户。

## 当前范围

已接通官方侧栏和主面板扩展，支持能力目录、本机模拟查询及任务记录。成果中心、场景专家和工作方法目前展示产品范围，尚未接入真实业务系统、LLM 自主规划、DSH Skill 执行或动态 HTML 成果。

已验证 macOS 官方 DSH Desktop 0.2.2-rc.3 的 UI。Windows 和其他版本仍需验证；遇到不兼容或安装错误，请记录系统、DSH 版本与错误信息。

## 停用和更新

在 DSH「插件」中停用或卸载 `@juslink/agent-center-ui`，按提示重启。更新使用 DSH 插件管理页提供的更新操作；不支持更新操作的版本可卸载后用同一地址重新安装。

## 文件说明

- `package.json`：插件包、客户端依赖与兼容版本声明。
- `cordis.patch.yml`：独立 Bundle 的 Host 注册。
- `index.js`：空 Host 入口，业务展示由客户端负责。
- `client.js`：已构建的 React 客户端，含图标和样式。

插件不包含用户配置、凭证、真实业务数据或安装脚本。未修改 DSH 官方源码。独立插件降低升级覆盖风险，但官方扩展接口变化后仍需兼容性验证。
