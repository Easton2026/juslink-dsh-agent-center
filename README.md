# 智链平台 DSH 插件 0.2.4

在 DSH 官方客户端内提供智链业务入口、已授权 MCP 工具、个人技能与 HTML 成果查看。通过独立 Plugin/Bundle 和 UI Slots 接入，不修改 DSH 安装包。工作区入口通过 SIT 网关检查 MCP 授权。业务工具由桌面端的智链 MCP 连接提供。

## 安装与更新

在 DSH「插件 → 添加插件」粘贴：

```text
https://github.com/Easton2026/juslink-dsh-agent-center.git
```

需要固定版本时，在地址后加 `#` 和本仓库完整提交标识。已安装旧版时，在插件页卸载旧版再添加新版，启用并按 DSH 提示重载或重启。需要安装电脑能够访问 GitHub；模型继续使用安装者自己的 DSH 配置。

## 工作区授权

每次从 DSH 打开智链平台，业务插件会重新连接当前 SIT 网关并读取 MCP 工具列表。授权失效时，会尝试使用本插件已登记的客户端刷新凭证。需要登录时点击「去授权」，在浏览器完成授权后返回插件。网络异常可点击「重试」。同一次使用中切换工具、历史、技能共用本次检查结果。

登录使用新的 PKCE 和 state，并在本机回调；凭证由 DSH 凭据服务保存。网关固定为 SIT 的 `juslink-api-gateway-sit`，仅在已知证书链错误时临时尝试同一 SIT 网关的 HTTP 入口。登录、注册与换取令牌均使用 HTTPS。旧脚本签发的访问凭证可接受入口检查；需要续期而本插件尚无客户端登记时会提示重新登录。

## 当前功能

- **工具**：上方场景专家区分“平台提供 / 我的专家”，支持对话式新建个人专家；平台包含物流综合分析、运输异常跟进。下方按当前账号授权展示网关返回的工具，五项天眼工具在页面上使用中文名称。点击「搜索订阅」进入对话，在该对话内查看查询结果与物流卡片。
- **历史**：查看旧版页面查询记录和已保存的 HTML 成果。对话本身及工具调用过程仍由 DSH 保存；尚未把所有对话、异步任务自动汇总为统一业务任务中心。
- **技能**：区分平台和个人，支持搜索、平台说明查看、在新对话中使用，以及通过 DSH 对话创建个人技能。

页面入口名称以当前源码为准。场景专家目前通过指令组合可用工具，尚无可视化专家配置器、自动排程或企业多租户隔离。

## 新建个人场景专家

在“工具 → 场景专家”点击“新建场景专家”，自动打开 DSH 新对话并提交 `/juslink-create-personal-expert` 创建指令。DSH 先询问要解决的问题；用户描述目标后，梳理必要输入、匹配实际可用的工具，形成步骤、判断规则、异常处理、完成条件与输出要求。缺少能力时说明缺口，不虚构接口。

确认方案并同意保存后，DSH 通过正常文件工具保存并读回核对；试跑为可选步骤。保存需遵守宿主现有审批，待审批或失败时不算已创建。保存成功返回“工具 → 我的专家”即可查看；点击“开始任务”会新开对话并询问本次所需信息，不默认填入演示单号。

专家为当前 DSH 用户根目录 `skills/juslink-expert-<唯一标识>/SKILL.md` 下的原生文件 Skill（DSH_HOME 或默认用户 .dsh），metadata 包含 plugin、scope: personal 和 kind: scenario-expert。description 为“【中文名】用途”。因为宿主目录接口不返回 metadata，页面使用专用名称前缀和文件位置区分个人专家与普通技能，这是展示约定，不是权限隔离；不会修改平台专家、随插件上传个人文件或跨设备同步。

创建流程注册为用户显式调用的内部 Skill，不自动由模型触发。专家每次执行需重新核对工具可用性：数据缺失、工具停用、调用失败时报告缺口；不提供定时调度或无人值守运行。

## 业务查询

在 DSH 对话中输入业务类型和单号，例如“查海运提单”加完整号码。插件直接在这轮对话下展示真实查询结果，有节点时可展开核对实际与预计时间。DSH 使用已配置的智链 SIT MCP 查询该授权账号可见的记录。查不到时可核对号码类型和授权范围。顶部租户切换为交互演示，查询范围以实际 MCP 授权为准。

## 个人技能

点击技能页“新增”，DSH 会询问用途和方法，再通过其文件工具保存原生 SKILL.md；文件操作遵守 DSH 的现有权限与审批流程。平台内置方法随插件提供，个人文件独立保存，更新插件不会覆盖。

智链个人技能采用专用名称前缀 `juslink-personal-`，目录与名称相同，YAML metadata.plugin 为 `@juslink/agent-center-ui`、scope 为 personal；description 使用“【中文名】用途”格式。当前页面按专用命名空间及文件位置筛选，这只是显示归属，不是原生插件权限绑定或多用户隔离。其他技能不会自动被归入智链。页面内个人技能正文编辑尚未实现。

## HTML 成果

生成 HTML 后，可明确要求“保存到成果中心”，调用 `juslink_artifact_save`。也可显式使用 `/juslink-artifact-publish`。

保存位置为当前会话工作目录下的 `juslink-artifacts/<标识>/index.html`，`index.json` 保存标题、摘要、时间及大小。保存成功以工具返回值为准；仅生成一个本地 HTML 或在聊天中展示，并不会自动进入索引。

页面用 `sandbox=""` iframe 预览，脚本、表单和弹窗禁用。HTML 应自包含、样式内联；单个文件上限 2 MB。成果不会同步到其他电脑或自动上传 GitHub。

## 已知限制

- 多个对话同时向同一目录保存成果时，当前索引更新会发生冲突；请暂时逐个保存。
- 成果页面按最近最多八个会话查找目录，尚没有严格的工作区选择与统一跨工作区列表。
- 成果发布 Skill 已注册到 DSH，但当前智链技能页的平台筛选只展示运输分析方法。
- 对话、任务与成果尚未建立完整的自动回流与状态恢复机制。
- macOS 官方 DSH 0.2.2-rc.3 已验证工具调用、技能创建回显和成果 iframe 预览；旧版完整桌面流程和 Windows 尚未实测。

兼容声明为 `0.2.1-rc.5 || >=0.2.2-rc.1 <0.3.0`。声明不等于已验证该范围内所有功能，也不承诺未来版本自动兼容。

## 源码与构建

本仓库包含完整前端源码、品牌资源和运行文件，无需下载第三方依赖。使用现代 Node.js 执行：

```sh
node build.mjs
node --check index.js
node --check client.js
```

`src/` 是前端源码，`assets/` 是构建资源，`client.js` 是已构建的客户端入口。运行包由 package.json 的 files 清单决定，包含 `artifact-store.js` 及其余工具、技能模块。

可在源码目录通过官方 CLI 本地开发安装：`dsh plugin --profile desktop add <本地目录>`。

可选生成 npm 兼容 TGZ 与 ZIP：

```sh
python3 release/package_release.py --output /tmp/juslink-release
```

打包脚本从同一个 files 清单取文件，排除个人技能、成果目录、备份、账号、凭据和本机状态。发布说明不包含任何真实业务数据。
